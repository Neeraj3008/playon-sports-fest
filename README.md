# PlayOn Sports Fest – MERN Tournament Registration Website

React + Express + MongoDB (Atlas) + Node.js. One server serves both the API (`/api`) and the built React site.

## 1. Run on your computer

**Needs:** Node.js 18+ and a free MongoDB Atlas database (see step 3 below for how to get the connection string).

```bash
# 1. install server packages
npm install

# 2. install client packages
npm install --prefix client

# 3. create your .env file
cp .env.example .env        # Windows: copy .env.example .env
#    then open .env and paste your MONGO_URI, set JWT_SECRET

# 4a. DEVELOPMENT (two terminals)
npm run dev                 # terminal 1 -> API on http://localhost:5000
npm run dev --prefix client # terminal 2 -> website on http://localhost:5173

# 4b. OR run it like production (one terminal)
npm run build
npm start                   # website + API on http://localhost:5000
```

**Admin account:** sign up with the email you put in `ADMIN_EMAIL` (default `admin@playon.com`) – that account gets the Dashboard.

The 5 events are inserted automatically on first start.

## 2. Deploy on Render (free)

1. Push this folder to a GitHub repository (`.env` and `node_modules` are already git-ignored).
2. On https://render.com → **New + → Blueprint** → pick the repo (it reads `render.yaml`).
   *(Or **New + → Web Service** and set: Build Command `npm install && npm run build`, Start Command `npm start`.)*
3. When asked, set the environment variables:
   - `MONGO_URI` – your Atlas connection string
   - `JWT_SECRET` – any long random string (auto-generated by the Blueprint)
   - `ADMIN_EMAIL` – email whose sign-up becomes admin
4. Click deploy. Your site will be live at `https://<service-name>.onrender.com`.

Note: Render's free tier sleeps after inactivity, so the first load can take ~50 seconds.

## 3. MongoDB Atlas setup (once)

1. Create a free **M0** cluster at https://cloud.mongodb.com.
2. **Database Access** → add a user (username + password).
3. **Network Access** → add IP `0.0.0.0/0` (so Render can connect).
4. **Connect → Drivers** → copy the string and use it as `MONGO_URI`, adding the database name:
   `mongodb+srv://USER:PASSWORD@cluster0.xxxxx.mongodb.net/playon?retryWrites=true&w=majority`
   (If the password has special characters, URL-encode them.)
